# Awesome shadcn Registries

A curated list of shadcn-compatible registries — places you can point
`npx shadcn@latest add` at to pull in components, blocks, and themes.

**51 registries**, each verified against its own `r/registry.json` endpoint. Install
instructions live on each project's site; links go straight there.

### Legend

`Pro` — free core, part of the catalogue needs a paid licence or key ·
`Pre-release` — registry exists, documented install not open yet ·
`Licence` — terms differ from plain MIT

## Contributing

1. The registry must be publicly reachable and use the shadcn registry schema.
2. Add your entry to the most fitting section, alphabetically among its siblings.
3. One line per entry: `- [Name](url) — Short description.` Aim for 100–140 characters,
   name what makes it different rather than listing every component.
4. Mark `Pro` if any part needs a paid licence or key, and add `Licence` where terms
   differ from plain MIT.
5. Say so in the PR if the registry is your own work.

No install commands or namespace docs here — the link is the documentation.
